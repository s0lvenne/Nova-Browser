## Обзор

**Nova Browser** — быстрый веб-браузер для Windows с открытым исходным кодом, созданный на **C#** и платформе **.NET 9 (WPF)** на базе движка Microsoft WebView2 (Chromium).

### Главные особенности
- **Движок**: Высокая скорость на базе .NET 9 и C# с аппаратным ускорением.
- **RAM Saver**: Глубокая оптимизация оперативной памяти без зависаний.
- **Умный Прокси**: Мгновенная смена прокси на лету без необходимости перезапуска браузера.
- **Безопасность**: Встроенная защита от стиллеров и блокировка рекламы.
- **Кастомизация**: Неоновая тёмная тема с акцентом `#BEF47B`, цветовые палитры и свои обои.
- **Ретро-аркада**: Игры (Flappy Bird, Тетрис, Dino) прямо на домашней странице.
- **Ноль телеметрии**: Полностью открытый исходный код под лицензией MIT.
