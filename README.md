## Overview

**Nova Browser** is an open-source web browser for Windows built with **C#** and **.NET 9 (WPF)** using the Microsoft WebView2 (Chromium) engine.

### Key Highlights
- **Engine**: Powered by .NET 9 and C# with hardware acceleration.
- **RAM Saver**: Deep memory optimization that keeps RAM usage minimal.
- **Live Proxy**: Switch proxies instantly on the fly without restarting the browser.
- **Security**: Built-in protection against stealers and aggressive ad tracking.
- **Customization**: Dark cyber-neon theme with `#BEF47B` accent and custom wallpapers.
- **Retro Arcade**: Built-in games (Flappy Bird, Tetris, Dino) on the new tab page.
- **Zero Telemetry**: 100% open source under the MIT License.
